Lightweight, security-conscious eCommerce for WordPress. A free alternative to WooCommerce and its paid extensions.

== Description ==
Cartel is a fast, no-bloat commerce plugin: one-page checkout, instant Buy Now, stock + order management, shipping/mailing/captcha integrations, and WooCommerce-compatible CSV import/export.

== Installation ==
1. Upload the `cartel` folder to `/wp-content/plugins/`.
2. Activate the plugin through the Plugins menu.
3. Visit Cartel → Settings to configure currency, captcha, mailing, and shipping integrations.
